TASK TRACKER
==============

Overview
---------
App concept for tracking completed tasks. The app will include points scored for completed tasks and a store to spend them to earn rewards set by the user, for example purchasing a special dessert. This is something that I think that I would find helpful and I hope to continue to refine it with time.

Back End
---------
-MySql database
-Java using Spring Boot
-Entities include users, days, tasks, categories, shop, and rewards
-CRUD operations

Front End
----------
-React
-Typescript
-CSS
